# Security

prodmask connects to production databases, so a security bug in it matters. Please report one privately, not in a public issue:

- on GitHub, with "Report a vulnerability" on the repository's [Security tab](https://github.com/ProdMask/ProdMask/security);
- or by email to support@prodmask.com.

Say which version you ran (`prodmask version`), what you ran, and what happened. Never include real data from a database: describe the shape of a value, or make up one with the same shape.

Fixes go into a new release, and its notes say what was fixed. They credit you if you'd like to be named. Only the latest release gets fixes.
